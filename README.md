# 💍 Royal Indian Mobile Wedding Invitation

An interactive, single-file luxury mobile wedding invitation website.

## ✨ Features
- **3D Opening Book**: Wine-velvet cover with gold Ganesh Ji medallion, 3D flip animation, and petal burst.
- **First Page**: Typography with blur-in name typing reveal inside a royal Mughal arch frame.
- **Save the Date Scroll**: Interactive pull-to-reveal parchment scroll with confetti celebration and live real-time countdown timer.
- **Wedding Festivities**: 3D swipeable card carousel for each ceremony (Mata Pujan, Haldi, Mehendi, Sangeet, Baraat & Pheras) with dress code color swatches.
- **Our Story**: Romantic chapter photo carousel with gold filigree frames.
- **Grand Reception**: Luxury deep wine velvet card with floral blooms and gold stars.
- **Location & Directions**: Interactive map card with animated travel route, Google Maps navigation, and 1-tap address copying.
- **Ambient Music**: Built-in Web Audio API Indian Raag Yaman classical synth (sitar, flute, tanpura) + custom MP3 upload support.
- **Live Details Customizer**: Built-in drawer to update couple names, parents, dates, venue, and export a personalized HTML invitation.

## 🚀 Deployment
Hosted on Vercel and available on GitHub.
